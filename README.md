# Mini Lista de Tareas (To-Do List)

Proyecto Final — Unidad 4: Aplicación de metodología de desarrollo según tendencia
**Metodología de Desarrollo de Software (DAWA-202)** — Instituto Superior Tecnológico La Troncal

Aplicación web sencilla de lista de tareas, desarrollada con HTML, CSS y JavaScript (sin frameworks), aplicando el ciclo completo de la metodología **SCRUM** con Jira, GitHub y GitHub Actions.

---

## 📋 Descripción del proyecto

La aplicación permite:
- Agregar una nueva tarea.
- Marcar una tarea como completada.
- Eliminar una tarea.
- Editar el texto de una tarea.
- Filtrar tareas (todas / pendientes / completadas).

---

## 🗂️ Historias de usuario implementadas (Sprint 1)

| ID | Historia de Usuario | Prioridad | Puntos | Estado |
|----|---------------------|-----------|--------|--------|
| HU-01 | Como usuario quiero agregar una nueva tarea para registrar pendientes. | Alta | 3 | LISTO |
| HU-02 | Como usuario quiero marcar una tarea como completada para ver mi progreso. | Alta | 2 | LISTO |
| HU-03 | Como usuario quiero eliminar una tarea para quitar pendientes ya no vigentes. | Alta | 2 | LISTO |

> HU-04 (editar tarea) y HU-05 (filtrar tareas) quedan planificadas para el **Sprint 2**.

Debería empezar a planificar mejor el tiempo antes de programar, para no tener que corregir errores sobre la marcha. También podría dividir cada historia en tareas más pequeñas antes de codificar.

**Continue (seguir haciendo):**
Debo seguir probando la aplicación en el navegador después de cada historia completada, porque eso me ayudó a detectar errores a tiempo.
